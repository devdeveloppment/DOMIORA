# CHAPITRE 6 : GUIDES D'UTILISATION

## 6.1. Guide d'utilisation pour les Clients/Utilisateurs

### 6.1.1 Inscription et création de compte

#### Étape 1 : Accès à la page d'inscription

1. Naviguez vers l'URL de DOMIORA : `https://domiora.com`
2. Cliquez sur le bouton "S'inscrire" dans le menu de navigation
3. Sélectionnez le type de compte : "Client" ou "Acheteur/Locataire"

#### Étape 2 : Formulaire d'inscription

Remplissez les informations requises :
- **Adresse e-mail** : Votre adresse e-mail valide
- **Mot de passe** : Minimum 8 caractères, incluant majuscules, minuscules et chiffres
- **Confirmation du mot de passe** : Identique au mot de passe
- **Prénom** : Votre prénom
- **Nom** : Votre nom de famille
- **Numéro de téléphone** : Format international (+228 90 56 78 48)
- **Pays** : Sélectionnez votre pays dans la liste déroulante

#### Étape 3 : Validation du compte

1. Un e-mail de confirmation est envoyé à votre adresse
2. Cliquez sur le lien de confirmation dans l'e-mail
3. Votre compte est activé et vous êtes connecté automatiquement

#### Étape 4 : Complétion du profil

1. Accédez à votre profil via le menu "Mon Compte"
2. Ajoutez une photo de profil (optionnel)
3. Complétez vos préférences de recherche
4. Configurez vos notifications

### 6.1.2 Recherche de biens immobiliers

#### Recherche simple

1. Utilisez la barre de recherche sur la page d'accueil
2. Entrez des mots-clés : ville, quartier, type de bien
3. Cliquez sur "Rechercher"
4. Les résultats s'affichent avec les informations essentielles

#### Recherche avancée

1. Cliquez sur "Recherche avancée" dans le menu
2. Filtrez par :
   - **Type de bien** : Appartement, Maison, Villa, Terrain, Bureau
   - **Type de transaction** : Location, Achat
   - **Prix** : Fourchette de prix minimum et maximum
   - **Localisation** : Ville, quartier, pays
   - **Caractéristiques** : Nombre de chambres, salles de bain, surface
   - **Équipements** : Piscine, garage, jardin, etc.
3. Cliquez sur "Appliquer les filtres"
4. Les résultats sont triés par pertinence

#### Utilisation de la carte interactive

1. Activez le mode "Carte" dans les résultats de recherche
2. Naviguez sur la carte pour explorer les biens par localisation
3. Cliquez sur les marqueurs pour voir les détails des biens
4. Utilisez les filtres pour affiner la recherche sur la carte

#### Recherche par commande (⌘K)

1. Appuyez sur `Ctrl+K` (Windows/Linux) ou `⌘+K` (Mac)
2. Tapez votre recherche en langage naturel
3. Exemples de requêtes :
   - "Maison 3 chambres à Lomé"
   - "Appartement sous 500000 FCFA"
   - "Villa avec piscine à Lomé"
4. Les résultats s'affichent instantanément

### 6.1.3 Consultation des détails d'un bien

#### Fiche détaillée d'un bien

Chaque fiche bien comprend :

**Informations générales**
- Titre et description complète
- Prix (location ou achat)
- Type de bien et transaction
- Adresse complète et localisation
- Surface en m²
- Nombre de chambres et salles de bain
- Année de construction (si disponible)

**Galerie photos**
- Jusqu'à 20 photos haute résolution
- Navigation par flèches ou miniatures
- Vue plein écran disponible

**Équipements et caractéristiques**
- Liste complète des équipements
- Commodités incluses
- Proximité des services (écoles, commerces, transports)

**Localisation**
- Carte interactive avec position exacte
- Vue satellite disponible
- Itinéraire vers le bien

**Informations sur le propriétaire/agent**
- Nom et photo de l'agent
- Spécialités et note moyenne
- Agence d'appartenance
- Autres biens du même agent

#### Visite virtuelle

Si disponible :
- Cliquez sur "Visite virtuelle 360°"
- Explorez le bien en immersion
- Naviguez entre les pièces
- Zoom sur les détails

### 6.1.4 Gestion des favoris

#### Ajouter un bien aux favoris

1. Cliquez sur l'icône "Cœur" sur la fiche d'un bien
2. Le bien est ajouté à votre liste de favoris
3. Une notification confirme l'ajout

#### Consulter les favoris

1. Accédez à "Mon Compte" → "Favoris"
2. Tous vos biens favoris sont affichés
3. Les favoris sont triés par date d'ajout
4. Vous pouvez les filtrer par type ou localisation

#### Supprimer un favori

1. Cliquez sur l'icône "Cœur" barré sur un bien favori
2. Confirmez la suppression
3. Le bien est retiré de votre liste

### 6.1.5 Contact avec les propriétaires

#### Première mise en relation

1. Sélectionnez un bien qui vous intéresse
2. Cliquez sur "Contacter le propriétaire"
3. Si aucune relation n'existe avec ce propriétaire :
   - Un écran de paiement FedaPay s'affiche
   - Le montant de la mise en relation est indiqué
   - Procédez au paiement sécurisé via FedaPay

#### Paiement FedaPay

1. Sélectionnez votre méthode de paiement (Mobile Money, carte bancaire)
2. Entrez vos coordonnées de paiement
3. Confirmez le montant
4. Validez la transaction
5. Une confirmation de paiement s'affiche

#### Accès à la messagerie

Après paiement réussi :
1. La relation Client-Propriétaire est créée
2. La messagerie devient accessible
3. Vous pouvez envoyer des messages au propriétaire
4. Vous pouvez demander une visite

#### Échange de messages

1. Accédez à "Messagerie" dans votre dashboard
2. Sélectionnez la conversation avec le propriétaire
3. Tapez votre message
4. Cliquez sur "Envoyer"
5. Les réponses du propriétaire apparaissent en temps réel

### 6.1.6 Demande de visite

#### Demander une visite

1. Depuis la fiche d'un bien, cliquez sur "Demander une visite"
2. Sélectionnez la date et l'heure souhaitées
3. Ajoutez un message explicatif (optionnel)
4. Confirmez votre demande

#### Suivi de la demande de visite

1. Le propriétaire reçoit votre demande
2. Il peut accepter, refuser ou proposer un autre créneau
3. Vous recevez une notification de sa réponse
4. Si accepté, les détails du rendez-vous sont confirmés

#### Annulation d'une visite

1. Accédez à "Mes visites" dans votre dashboard
2. Sélectionnez la visite à annuler
3. Cliquez sur "Annuler"
4. Confirmez l'annulation
5. Le propriétaire est notifié automatiquement

### 6.1.7 Utilisation de l'assistant IA

#### Accès à l'assistant IA

1. Cliquez sur l'icône de chat en bas à droite de l'écran
2. L'assistant IA s'ouvre dans une fenêtre flottante
3. Commencez à converser en langage naturel

#### Types de requêtes possibles

**Recherche de biens**
- "Je cherche une maison 3 chambres à Lomé"
- "Appartement moderne sous 400000 FCFA"
- "Villa avec piscine dans les environs de Lomé"

**Questions sur les prix**
- "Quel est le prix moyen d'un appartement 2 chambres ?"
- "Les prix sont-ils négociables ?"

**Informations générales**
- "Comment fonctionne DOMIORA ?"
- "Quels sont les documents nécessaires pour louer ?"
- "Comment créer un compte ?"

#### Fonctionnalités avancées

- Historique de conversation conservé
- Suggestions automatiques de biens
- Réponses contextuelles basées sur votre profil
- Navigation directe vers les biens recommandés

### 6.1.8 Gestion du profil personnel

#### Modification des informations

1. Accédez à "Mon Compte" → "Profil"
2. Modifiez vos informations personnelles
3. Mettez à jour votre photo de profil
4. Changez votre mot de passe si nécessaire
5. Sauvegardez les modifications

#### Préférences de notification

1. Accédez à "Mon Compte" → "Notifications"
2. Configurez vos préférences :
   - Notifications par e-mail
   - Notifications push
   - Alertes nouveaux biens
   - Mises à jour de vos demandes
3. Sauvegardez vos préférences

#### Suppression de compte

1. Accédez à "Mon Compte" → "Paramètres"
2. Cliquez sur "Supprimer mon compte"
3. Confirmez votre intention
4. Entrez votre mot de passe
5. Votre compte et toutes vos données sont supprimés

## 6.2. Guide d'utilisation pour les Propriétaires/Agents

### 6.2.1 Inscription et vérification

#### Inscription propriétaire

1. Naviguez vers DOMIORA et cliquez sur "S'inscrire"
2. Sélectionnez "Propriétaire/Agent immobilier"
3. Remplissez le formulaire d'inscription :
   - Informations personnelles complètes
   - Nom de l'agence (si applicable)
   - Numéro de licence professionnelle
   - Coordonnées de contact
4. Validez votre compte par e-mail

#### Soumission des documents d'identité

1. Connectez-vous à votre compte propriétaire
2. Accédez à "Vérification d'identité"
3. Téléchargez les documents requis :
   - Carte d'identité recto
   - Carte d'identité verso
   - Type de document (CNI, passeport, etc.)
   - Numéro du document
4. Cliquez sur "Soumettre pour vérification"

#### Processus de vérification

**Statut "En attente de vérification"**
- Votre compte passe en attente
- Un message d'information s'affiche :
  > "Vérification de votre identité en cours. Pour garantir la sécurité de notre plateforme et lutter contre les fraudes, DOMIORA procède à une vérification de votre identité et de votre bien. Un de nos agents pourra vous contacter afin d'effectuer une vérification sur place. Merci de patienter. Votre compte et vos annonces seront activés après validation de cette étape par notre équipe."

**Vérification physique**
- Un agent de vérification peut vous contacter
- Planification d'un rendez-vous sur place
- Vérification de votre identité et de vos biens
- Rédaction d'un rapport de vérification

**Validation finale**
- L'administrateur analyse le rapport
- Décision de validation ou de refus
- Notification par e-mail du résultat

### 6.2.2 Gestion des biens immobiliers

#### Création d'une annonce

1. Accédez à "Mes biens" → "Ajouter un bien"
2. Remplissez les informations générales :
   - Titre de l'annonce
   - Type de bien (appartement, maison, villa, etc.)
   - Type de transaction (location, achat)
   - Prix
   - Description détaillée

3. Ajoutez les caractéristiques :
   - Surface en m²
   - Nombre de chambres
   - Nombre de salles de bain
   - Année de construction
   - État du bien

4. Localisation :
   - Adresse complète
   - Ville
   - Pays
   - Coordonnées GPS (optionnel)

5. Équipements :
   - Cochez les équipements disponibles
   - Ajoutez des équipements personnalisés si nécessaire

6. Photos :
   - Téléchargez jusqu'à 20 photos
   - Formats acceptés : JPG, PNG, WebP
   - Taille maximale : 5 Mo par photo
   - La première photo devient la photo principale

7. Visite virtuelle (optionnel) :
   - Collez le lien Matterport/YouTube
   - Description de la visite virtuelle

8. Publication :
   - Enregistrez comme brouillon
   - Ou soumettez pour validation
   - Note : Si votre compte n'est pas validé, l'annonce reste en brouillon

#### Modification d'une annonce

1. Accédez à "Mes biens"
2. Sélectionnez l'annonce à modifier
3. Modifiez les informations souhaitées
4. Ajoutez ou supprimez des photos
5. Sauvegardez les modifications
6. Si l'annonce est publiée, elle doit être revalidée après modification

#### Suppression d'une annonce

1. Sélectionnez l'annonce dans "Mes biens"
2. Cliquez sur "Supprimer"
3. Confirmez la suppression
4. L'annonce est définitivement supprimée
5. Les demandes en cours sont notifiées

#### Gestion des photos

**Ajout de photos**
- Glissez-déposez les fichiers
- Ou cliquez sur "Parcourir"
- Les photos sont automatiquement optimisées
- Elles sont stockées sur Cloudinary

**Organisation des photos**
- Faites glisser pour réorganiser
- La première photo est la photo principale
- Les photos apparaissent dans l'ordre sur la fiche

**Suppression de photos**
- Cliquez sur la croix sur une photo
- Confirmez la suppression
- Minimum 1 photo requis

### 6.2.3 Gestion des demandes clients

#### Consultation des demandes

1. Accédez à "Demandes" dans votre dashboard
2. Les demandes sont classées par statut :
   - Nouvelles
   - En cours
   - Acceptées
   - Refusées
   - Terminées

3. Chaque demande affiche :
   - Informations du client
   - Bien concerné
   - Type de demande (visite, location, achat)
   - Date de la demande
   - Message du client

#### Traitement d'une demande de visite

1. Sélectionnez une demande de visite
2. Consultez les détails du client
3. Répondez en choisissant :
   - **Accepter** : Confirmez le créneau proposé
   - **Proposer un autre créneau** : Suggérez une date/heure alternative
   - **Refuser** : Indiquez le motif du refus

4. Ajoutez un message explicatif
5. Le client est notifié automatiquement

#### Traitement d'une demande de location/achat

1. Sélectionnez la demande
2. Consultez le profil du client
3. Vérifiez sa solvabilité (si applicable)
4. Répondez :
   - **Accepter** : Initiez le processus de transaction
   - **Demander des informations** : Requestez des documents supplémentaires
   - **Refuser** : Indiquez le motif

#### Suivi des transactions

1. Accédez à "Transactions" dans votre dashboard
2. Consultez l'historique complet
3. Visualisez les commissions générées
4. Exportez les rapports

### 6.2.4 Messagerie avec les clients

#### Consultation des avis

### 6.2.7 Publication et validation des annonces

#### Statut des annonces

**Brouillon**
- Enregistré mais non soumis
- Modifiable à tout moment
- Non visible publiquement

**En attente de validation**
- Soumis pour validation
- En attente de l'administrateur
- Non visible publiquement

**Publié**
- Validé par l'administrateur
- Visible publiquement
- Apparaît dans les recherches

**Suspendu**
- Temporairement retiré
- Modifiable
- Peut être republié

**Refusé**
- Rejeté par l'administrateur
- Motif du refus indiqué
- Corrigez et soumettez à nouveau

#### Validation par l'administrateur

1. L'administrateur examine votre annonce
2. Vérifie la conformité avec les règles
3. Peut demander des modifications
4. Valide ou refuse l'annonce
5. Vous êtes notifié du résultat

## 6.3. Guide d'utilisation pour les Administrateurs

### 6.3.1 Accès au panneau d'administration

#### Connexion administrateur

1. Naviguez vers `https://domiora.com/admin-panel/`
2. Connectez-vous avec vos identifiants administrateur
3. Le tableau de bord administrateur s'affiche

#### Structure du panneau d'administration

Le panneau comprend plusieurs sections :
- **Vue d'ensemble** : Statistiques globales
- **Utilisateurs** : Gestion des comptes
- **Propriétaires** : Validation des propriétaires
- **Biens** : Validation des annonces
- **Transactions** : Supervision des paiements
- **Agents de vérification** : Gestion des agents
- **Paramètres** : Configuration système
- **Rapports** : Statistiques et export

### 6.3.2 Gestion des utilisateurs

#### Consultation des utilisateurs

1. Accédez à "Utilisateurs"
2. Liste complète de tous les utilisateurs
3. Filtres par :
   - Type (client, propriétaire, admin)
   - Statut (actif, suspendu, en attente)
   - Date d'inscription
4. Recherche par nom ou e-mail

#### Détails d'un utilisateur

Cliquez sur un utilisateur pour voir :
- Informations personnelles
- Historique d'activité
- Statut du compte
- Relations avec les propriétaires
- Transactions effectuées

#### Actions sur les utilisateurs

**Activation/Suspension**
- Activer un compte en attente
- Suspendre un compte problématique
- Réactiver un compte suspendu

**Modification**
- Modifier les informations utilisateur
- Changer le rôle
- Réinitialiser le mot de passe

**Suppression**
- Supprimer un compte (avec confirmation)
- Les données sont anonymisées mais conservées

### 6.3.3 Validation des propriétaires

#### Processus de validation

**1. Consultation du dossier**
- Accédez à "Propriétaires" → "En attente"
- Sélectionnez un propriétaire
- Consultez les documents soumis
- Vérifiez les informations fournies

**2. Demande de vérification physique**
- Cliquez sur "Demander vérification physique"
- Sélectionnez un agent de vérification
- Attribuez la mission
- L'agent reçoit les informations de mission

**3. Consultation du rapport de vérification**
- L'agent soumet son rapport
- Consultez les constatations
- Analysez les photos et justificatifs
- Évaluez la conformité

**4. Décision finale**
- **Valider** : Le propriétaire peut publier ses annonces
- **Refuser** : Indiquez le motif du refus
- **Demander complément** : Requestez des informations supplémentaires

**5. Notification**
- Le propriétaire est notifié automatiquement
- Un e-mail de confirmation ou de refus est envoyé
- Le statut du compte est mis à jour

#### Statuts des propriétaires

- **En attente** : Documents soumis, en attente de vérification
- **En vérification** : Vérification physique en cours
- **Validé** : Peut publier des annonces
- **Refusé** : Compte refusé
- **Suspendu** : Compte temporairement suspendu

### 6.3.4 Validation des annonces

#### Consultation des annonces en attente

1. Accédez à "Biens" → "En attente"
2. Liste des annonces soumises
3. Filtres par type, prix, localisation

   - Prix
   - Description

#### Actions de validation

**Valider**

- Apparaît dans les recherches
- Le propriétaire est notifié

**Refuser**
- Indiquez le motif du refus
- Le propriétaire peut modifier et resoumettre

**Suspendre**
- Retirez temporairement l'annonce

## 6.4. Guide d'utilisation de l'assistant IA

### 6.4.1 Présentation de l'assistant IA

L'assistant IA de DOMIORA est un système conversationnel intelligent propulsé par Mistral API, conçu pour aider les utilisateurs à trouver des biens immobiliers et répondre à leurs questions sur la plateforme.

### 6.4.2 Accès à l'assistant

#### Interface principale

1. Cliquez sur l'icône de chat en bas à droite de l'écran
2. L'assistant s'ouvre dans une fenêtre flottante
3. L'interface est accessible depuis toutes les pages

#### Caractéristiques de l'interface

- Design moderne et intuitif
- Historique de conversation conservé
- Réponses en temps réel
- Suggestions automatiques
- Navigation directe vers les biens

### 6.4.3 Types de requêtes supportées

#### Recherche de biens

**Recherche par critères**
- "Je cherche une maison 3 chambres à Lomé"
- "Appartement moderne sous 500000 FCFA"
- "Villa avec piscine dans les environs de Lomé"

**Recherche par caractéristiques**
- "Bien avec garage et jardin"
- "Appartement proche du centre-ville"
- "Maison récente avec bonne isolation"

**Recherche par budget**
- "Logement entre 200000 et 400000 FCFA"
- "Biens de luxe au-dessus de 1 million FCFA"

#### Questions sur les prix

- "Quel est le prix moyen d'un appartement 2 chambres ?"
- "Les prix sont-ils négociables ?"
- "Quels sont les frais supplémentaires ?"

#### Questions sur le processus

- "Comment fonctionne DOMIORA ?"
- "Quels sont les documents nécessaires pour louer ?"
- "Comment créer un compte ?"
- "Comment contacter un propriétaire ?"

#### Questions sur les services

- "Proposez-vous des visites virtuelles ?"
- "Comment fonctionne la vérification des propriétaires ?"
- "Quels sont les moyens de paiement acceptés ?"

### 6.4.4 Fonctionnalités avancées

#### Suggestions intelligentes

L'assistant propose automatiquement :
- Biens correspondant à vos critères
- Alternatives si aucun résultat exact
- Biens similaires dans le même quartier
- Nouveaux biens correspondant à votre historique

#### Historique contextuel

L'assistant se souvient :
- De vos recherches précédentes
- De vos préférences
- De vos favoris
- De vos conversations

#### Navigation directe

Chaque suggestion inclut :
- Lien direct vers la fiche du bien
- Aperçu des informations clés
- Photo principale
- Prix et localisation

#### Multi-langue

L'assistant comprend :
- Français (langue principale)
- Anglais
- Réponses adaptées à la langue de la requête

### 6.4.5 Bonnes pratiques d'utilisation

#### Formulation des requêtes

**✅ Bonnes pratiques**
- Soyez spécifique sur vos critères
- Indiquez votre budget si possible
- Précisez la localisation souhaitée
- Utilisez des termes clairs

**❌ À éviter**
- Requêtes trop vagues
- Critères contradictoires
- Informations incomplètes

#### Interprétation des réponses

- Vérifiez que les résultats correspondent à vos critères
- Cliquez sur les liens pour voir les détails complets
- Utilisez les filtres pour affiner la recherche
- N'hésitez pas à reformuler votre requête

#### Limitations

- L'assistant ne peut pas réserver des visites
- Il ne peut pas négocier les prix
- Il n'a pas accès aux informations privées
- Les suggestions sont basées sur les données disponibles

### 6.4.6 Dépannage

#### Si l'assistant ne répond pas

1. Vérifiez votre connexion internet
2. Rechargez la page
3. Essayez de reformuler votre requête
4. Contactez le support si le problème persiste

#### Si les résultats ne sont pas pertinents

1. Soyez plus spécifique dans votre requête
2. Utilisez les filtres de recherche avancée
3. Essayez différents termes
4. Consultez le catalogue directement

#### Si l'assistant est lent

1. Vérifiez votre connexion internet
2. Ferrez d'autres onglets
3. Essayez pendant les heures creuses
4. Contactez le support si le problème persiste

- Alertes système

#### Paramètres de notification

- Fréquence des notifications
- Types de notifications à recevoir
- Méthode de notification (e-mail, push, SMS)

2. Sélectionnez "Mode sombre"

#### Persistance du thème

- Votre choix est sauvegardé
- Le thème est appliqué à toutes les pages
- Reprise automatique à la connexion
